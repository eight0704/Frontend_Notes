# 8. CSS 鼠标属性

| css 属性名 | 功能 | 属性值 |
| --- | --- | --- |
| `cursor` | 设置鼠标光标的样式 | `pointer`：小手<br>`move`：移动图标<br>`text`：文字选择器<br>`crosshair`：十字架<br>`wait`：等待<br>`help`：帮助 |

## 扩展：自定义鼠标图标

```css
/* 自定义鼠标光标 */
cursor: url("./arrow.png"), pointer;
```

## 示例

```css
a {
    cursor: grab;      /* 抓取手势 */
}

button {
    cursor: pointer;   /* 小手，按钮最常用 */
}

input {
    cursor: move;      /* 移动图标 */
}
```
