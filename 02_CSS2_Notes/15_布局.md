# 布局

## 1. 版心

- 在 PC 端网页中，一般都会有一个固定宽度且水平居中的盒子，来显示网页的主要内容，这是网页的**版心**。
- 版心的宽度一般是 **960 ~ 1200 像素**之间。
- 版心可以是**一个**，也可以是**多个**。

### 示例

```css
/* 最常见的版心写法：固定宽度 + 水平居中 */
.container {
    width: 1200px;
    margin: 0 auto;
}

/* 适配小屏：设置最大宽度 */
.container {
    max-width: 1200px;
    margin: 0 auto;
    padding: 0 15px;
}
```

```html
<div class="container">
    <!-- 网页主要内容 -->
</div>
```

### 说明

- `width` 固定 + `margin: 0 auto` 是版心水平居中的标准做法，前提是元素为**块级**且有明确宽度。
- 常见版心宽度：`1200px`、`1180px`、`1100px`、`960px`。
- 一个页面可以有多个版心：比如顶部导航一个、主体内容一个、页脚一个，宽度可以不同。
- 现在做响应式页面时，更常用 `max-width` + `padding`，让大屏不超宽、小屏不贴边。

## 2. 常用布局名词

| 位置 | 英文命名 |
| --- | --- |
| 顶部导航条 | `topbar` |
| 页头 | `header`、`page-header` |
| 导航 | `nav`、`navigator`、`navbar` |
| 搜索框 | `search`、`search-box` |
| 横幅、广告、宣传图 | `banner` |
| 主要内容 | `content`、`main` |
| 侧边栏 | `aside`、`sidebar` |
| 页脚 | `footer`、`page-footer` |

## 3. 重置默认样式

### 1. 为什么需要重置

很多元素都有默认样式，比如：

1. `p` 元素有默认的上下 `margin`。
2. `h1~h6` 标题也有上下 `margin`，且字体加粗。
3. `body` 元素有默认的 `8px` 外边距。
4. 超链接有默认的文字颜色和下划线。
5. `ul` 元素有默认的左 `padding`。
6. ……

在早期，元素默认样式能够让我们快速地绘制网页；但如今网页的设计越来越复杂，内容越来越多，而且很精细，这些默认样式会给我们绘制页面带来麻烦；而且这些默认样式，在不同的浏览器上呈现出来的效果也不一样，所以我们需要重置这些默认样式。

### 2. 方案一：使用全局选择器

```css
* {
    margin: 0;
    padding: 0;
    /* ...... */
}
```

此种方法，在简单案例中可以用一下，但**实际开发中不会使用**，因为：

- `*` 选择的是所有元素，而并不是所有的元素都有默认样式；
- 我们重置时，有时候是需要做**特定处理**的，比如：想让 `a` 元素的文字是灰色，其他元素文字是蓝色。

### 3. 方案二：reset.css

选择到具有默认样式的元素，清空其默认的样式。

```css
/* 一个简化的 reset.css 示例 */
* {
    box-sizing: border-box;
}

body,
h1, h2, h3, h4, h5, h6,
p, ul, ol, figure {
    margin: 0;
}

ul, ol {
    padding: 0;
    list-style: none;
}

a {
    text-decoration: none;
    color: inherit;
}

img {
    display: block;
    max-width: 100%;
}
```

经过 `reset` 后的网页，好似“一张白纸”，开发人员可根据设计稿，精细地去添加具体的样式。

### 4. 方案三：Normalize.css

`Normalize.css` 是一种最新方案，它在清除默认样式的基础上，**保留了一些有价值的默认样式**。

- 官网地址：`http://necolas.github.io/normalize.css/`

相对于 `reset.css`，`Normalize.css` 有如下优点：

1. 保护了有价值的默认样式，而不是完全去掉它们。
2. 为大部分 HTML 元素提供一般化的样式。
3. 新增对 HTML5 元素的设置。
4. 对并集选择器的使用比较谨慎，有效避免调试工具杂乱。

> 备注：`Normalize.css` 的重置，和 `reset.css` 相比，**更加温和**，开发时可根据实际情况进行选择。
