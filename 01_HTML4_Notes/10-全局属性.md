# 全局属性

常用的全局属性如下：

| 属性名 | 含义 |
| --- | --- |
| `id` | 给标签指定唯一标识，注意：`id` 不能重复。<br>作用：可以让 `label` 标签与表单控件相关联；也可以与 CSS、JavaScript 配合使用。<br>注意：不能在以下 HTML 元素中使用：`<head>`、`<html>`、`<meta>`、`<script>`、`<style>`、`<title>`。 |
| `class` | 给标签指定类名，随后通过 CSS 就可以给标签设置样式。 |
| `style` | 给标签设置 CSS 样式。 |
| `dir` | 内容的方向，值：`ltr`、`rtl`。<br>注意：不能在以下 HTML 元素中使用：`<head>`、`<html>`、`<meta>`、`<script>`、`<style>`、`<title>`。 |
| `title` | 给标签设置一个文字提示，一般超链接和图片用得比较多。 |
| `lang` | 给标签指定语言，具体规范和可选值请参考[语言设置](02-结构.md#语言设置)。<br>注意：不能在以下 HTML 元素中使用：`<head>`、`<html>`、`<meta>`、`<script>`、`<style>`、`<title>`。 |

完整全局属性列表请参考 [MDN: 全局属性](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Global_attributes)。
