# 超链接

## 跳转页面

主要作用：从当前页面进行跳转。

| 标签名 | 标签语义 | 常用属性 | 单 / 双标签 |
| --- | --- | --- | --- |
| `a` | 超链接 | `href`：要跳转的具体位置。<br>`target`：跳转时如何打开页面，常用值如下：<br>`_self`：在本页签中打开。<br>`_blank`：在新页签中打开。 | 双 |

```html
<!-- 跳转其他网页 -->
<a href="https://www.jd.com/" target="_blank">去京东</a>
```

```html
<!-- 跳转本地网页 -->
<a href="./18_HTML排版标签.html" target="_self">去看排版标签</a>
```

注意点：

- 代码中的多个空格、多个回车，都会被浏览器解析成一个空格！
- 虽然 `a` 是行内元素，但 `a` 元素可以包裹除它自身外的任何元素！

## 跳转文件

```html
<body>
  <!-- 都是浏览器可以直接打开的文件 -->
  <a href="./resource/blueming.jpg">看IU</a>
  <a href="./resource/线条小狗.gif">看小狗</a>

  <!-- 浏览器不可以直接打开的文件 -->
  <a href="./resource/ting_en_setup.zip">内部资源</a>

  <!-- 浏览器可以直接打开，但要强制触发下载 -->
  <a href="./resource/blueming.jpg" download="IU照片">强制下载IU的图片</a>
</body>
```

注意：

1. 若浏览器无法打开文件，则会引导用户下载。
2. 若想强制触发下载，请使用 `download` 属性，属性值即为下载文件的名称。

## 跳转锚点

什么是锚点？—— 网页中的一个标记点。

具体使用方式如下。

### 第一步：设置锚点

```html
<!-- 第一种方式：a 标签配合 name 属性 -->
<a name="test1"></a>

<!-- 第二种方式：其他标签配合 id 属性 -->
<h2 id="test2">我是一个位置</h2>
<p id="blueming">这是 blueming 照片</p>
```

注意点：

- 具有 `href` 属性的 `a` 标签是超链接，具有 `name` 属性的 `a` 标签是锚点。
- `name` 和 `id` 都是区分大小写的，且 `id` 最好别是数字开头。

### 第二步：跳转锚点

```html
<!-- 跳转到 test1 锚点 -->
<a href="#test1">去 test1 锚点</a>
```

```html
<!-- 跳到本页面顶部 -->
<a href="#">回到顶部</a>
```

```html
<!-- 跳转到其他页面锚点 -->
<a href="demo.html#test1">去 demo.html 页面的 test1 锚点</a>
```

```html
<!-- 刷新本页面 -->
<a href="">刷新本页面</a>
```

```html
<!-- 执行一段 js，javascript:; -->
<a href="javascript:alert(1);">点我弹窗</a>
```

## 唤起指定应用

通过 `a` 标签，可以唤起设备应用程序。

```html
<!-- 唤起设备拨号 -->
<a href="tel:10010">电话联系</a>
```

```html
<!-- 唤起设备发送邮件 -->
<a href="mailto:10010@qq.com">邮件联系</a>
```

```html
<!-- 唤起设备发送短信 -->
<a href="sms:10086">短信联系</a>
```
