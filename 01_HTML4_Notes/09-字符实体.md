# 字符实体

在 HTML 中，我们可以用一种特殊形式的内容来表示某个符号，这种特殊形式的内容就是 HTML 实体。比如小于号 `<` 用于定义 HTML 标签的开始。如果我们希望浏览器正确地显示这些字符，就必须在 HTML 源码中插入字符实体。

字符实体由三部分组成：一个 `&` 和一个实体名称（或者一个 `#` 和一个实体编号），最后加上一个分号 `;`。

常见字符实体汇总：

| 描述 | 实体名称 | 实体编号 |
| --- | --- | --- |
| 空格 | `&nbsp;` | `&#160;` |
| 小于号 | `&lt;` | `&#60;` |
| 大于号 | `&gt;` | `&#62;` |
| 和号 | `&amp;` | `&#38;` |
| 引号 | `&quot;` | `&#34;` |
| 反引号 | `&acute;` | `&#180;` |
| 分（cent） | `&cent;` | `&#162;` |
| 镑（pound） | `&pound;` | `&#163;` |
| 元（yen） | `&yen;` | `&#165;` |
| 欧元（euro） | `&euro;` | `&#8364;` |
| 版权（copyright） | `&copy;` | `&#169;` |
| 注册商标 | `&reg;` | `&#174;` |
| 商标 | `&trade;` | `&#8482;` |
| 乘号 | `&times;` | `&#215;` |
| 除号 | `&divide;` | `&#247;` |

完整实体列表请参考 [HTML Standard: Named Character References](https://html.spec.whatwg.org/multipage/named-characters.html)。
