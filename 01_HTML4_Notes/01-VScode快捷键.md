# 快捷键

代码编写常用快捷键：

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + /` | 单行注释 / 取消注释 `//` |
| `Shift + Alt + A` | 块多行注释 `/* */` |
| `Ctrl + Shift + K` | 删除整行 |
| `Alt + ↑ / ↓` | 上下移动整行代码 |
| `Shift + Alt + ↑ / ↓` | 复制一行到上 / 下方 |
| `Ctrl + Enter` | 在当前行下方新建空行 |
| `Ctrl + Shift + Enter` | 在当前行上方新建空行 |
| `Shift + Alt + F` | 格式化代码（整理缩进，非常重要） |
| `Ctrl + [` | 代码向左缩进 |
| `Ctrl + ]` | 代码向右缩进 |
